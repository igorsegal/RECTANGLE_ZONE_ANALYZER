# RZA Block20 — лимитный вход на 50% confirmation-свечи

## Гипотеза

После того как поглощение полностью подтверждено закрытием H1, не входим сразу по рынку.

Ставим лимитный ордер на середину тела последней confirmation-свечи:

LIMIT50 = (ConfirmOpen + ConfirmClose) / 2

Это одна фиксированная гипотеза. Никакой сетки 38.2/50/61.8 и никакой оптимизации нет.

## Термины

В текущем коде:
- ENGULF_2 = исходная свеча + одна поглощающая confirmation-свеча;
- ENGULF_3 = исходная свеча + две свечи нового направления, вторая завершает поглощение.

То есть пользовательское «однобарное поглощение» соответствует ENGULF_2, а «двухбарное поглощение» — ENGULF_3.

В обоих случаях 50% берётся только от тела последней confirmation-свечи, которая окончательно завершила поглощение.

## Жизнь лимитного ордера

Ордер активен с первого M5 следующего H1 после confirmation-close.
Ордер отменяется при канонической инвалидизации родительского ABS_TRACK-прямоугольника.

Если цена не откатила к 50% до инвалидизации — NO_FILL, сделки нет.

## Исполнение

BUY:
- геометрический trigger строится на Bid midpoint;
- исполнение учитывает исторический XFBAR spread;
- при gap через уровень берётся фактическая доступная цена.

SELL:
- trigger и исполнение по Bid;
- при gap используется фактическая лучшая доступная цена.

После входа:
- TP = 89 quote-points;
- SL = 233 quote-points.

TP/SL в одной M5 при неизвестном порядке трактуются консервативно.

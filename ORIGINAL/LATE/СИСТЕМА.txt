┌─────────────────────────────────────────────────────────────────────┐
│                    УРОВЕНЬ 4: BACKTEST ENGINE                      │
├─────────────────────────────────────────────────────────────────────┤
│  • Для каждого FinalRule:                                          │
│      - Проход по истории, поиск касаний под фильтры правила        │
│      - Открытие сделки: entry_price = close ± spread/2             │
│      - Расчёт лота: risk_amount = deposit * risk_pct / 100         │
│                    lot = risk_amount / (SL_points * point * tick)  │
│      - Симуляция в ДВУХ режимах:                                   │
│          LOCAL: TP = ReactionATR, SL = BreakoutATR                 │
│          STRUCTURAL: TP = next opposite zone, SL = zone breakout   │
│      - Учёт MaxConcurrentPositions                                 │
│      - Сбор статистики: trades[], equity_curve, drawdown           │
│  → Выход: BacktestResult { profit, winrate, PF, maxDD, Sharpe }    │
